# Presentation boundary

Accessible Flutter screens, widgets, and UI state adapters belong here.
Presentation may depend on `application` and `domain` contracts, but never on
concrete data or platform implementations.

The inventory browser exposes visible alternatives for every item action,
spoken mutation feedback, exact location/quantity/state details, explicit
unknown-date language, and separate Use First and Thaw Queue views. Planning
dates and thaw history are never presented as food-safety guidance.
